# 🔐 Caesar Cipher Secure Chat

A real-time encrypted chat application demonstrating the Caesar Cipher substitution cipher with admin controls, brute-force visualization, and step-by-step encryption debugging.

> ⚠️ **Educational Purpose Only** – Caesar cipher is cryptographically weak and should NOT be used for real-world security.

---

## 🚀 How to Run This Project

### Prerequisites
- **Node.js** (v16 or higher) – [Download here](https://nodejs.org/)
- **npm** (comes with Node.js)

### Quick Start (3 Steps)

```bash
# 1. Install dependencies
npm install

# 2. Start the server
node server.js
